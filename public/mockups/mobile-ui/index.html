MOBILE UI/UX MOCKUPS

Five different approaches to improve the mobile experience for StoryMaps. Each mockup addresses the crowded split-screen layout in a different way.

MOCKUP 01

Bottom Tab Navigation

iOS/Android-style bottom tabs for switching between full-screen views. Clean separation between map, list, timeline, and stats.

  • Full-screen content visibility
  • Familiar navigation pattern
  • Quick access to all sections
View Mockup
MOCKUP 02

Draggable Bottom Sheet

Google Maps-style bottom sheet that can be dragged up to reveal the list. Map is always visible as primary content.

  • Map always visible
  • Natural gesture interaction
  • Three height states
View Mockup
MOCKUP 03

Floating Action Button

Minimal UI with a central FAB that expands to show navigation options. List slides in from the side when selected.

  • Maximum map visibility
  • One-button access to all
  • Clean, minimal interface
View Mockup
MOCKUP 04

Swipeable Full-Screen Views

Horizontal swipe between full-screen views with page dots indicator. Each view gets maximum screen real estate.

  • Full content for each view
  • Natural swipe gestures
  • Includes dedicated timeline
View Mockup
MOCKUP 05

Split View with Maximize

Enhanced split view with toggles to maximize either pane. Keeps both views accessible while allowing focus.

  • Preserves split for context
  • One-tap maximize
  • Flexible view ratios

Recommendation

For StoryMaps, Mockup 2 (Bottom Sheet) or Mockup 5 (Split with Maximize) are recommended. The bottom sheet provides a familiar, map-centric experience similar to Google Maps, while the split maximize option preserves the ability to see both views when needed. Consider user testing to determine which better suits your audience.
